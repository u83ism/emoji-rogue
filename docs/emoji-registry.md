# 絵文字レジストリ

「今どの絵文字が何に使われているか」の台帳。**手動更新前提**(`docs/catalog.md`のようなSSOT生成はしない — 敵・アイテム・わな以外のグリフ(地形・プレイヤー・chrome等)も含むため、生成元を一本化できない)。

新しい絵文字を検討するときは、まず本ファイルで「既に使われていないか」「過去に検討して却下していないか」を確認してから`docs/emoji-policy.md`の基準に照らす。選定基準そのもの(VS16・EAW等の技術的な判定方法)は`docs/emoji-policy.md`を参照 — 本ファイルは「個々のグリフが何に割り当て済み/却下済みか」の実績台帳。

### 敵(`ENEMY_GLYPHS`)

原作Rogueは26種(A〜Zの頭文字1体ずつ)で、原作にはモンスターの見た目設定がほぼ無い(ASCII1文字表示のみ)。以下の「補足」列は原作の元ネタ・原作との対応関係の調査メモ(2026-07-28、`/goal`セッション)。

| 絵文字 | 敵 | 補足 |
|---|---|---|
| 🧟 | ゾンビ | 原作Z(Zombie)、名称も一致 |
| 🦇 | コウモリ | 原作B(Bat) |
| 👺 | 盗賊 | 原作L(Leprechaun、金貨を盗んでテレポート逃走)の機能面だけを再現した代替と推定。ゴブリン仮面の絵文字自体はレプラコーンの元ネタである妖精とは無関係で、「盗んで消える」という挙動のみ引き継いでいる |
| 👻 | ニンフ | 原作N(Nymph)、名称も一致。持ち物を盗んでテレポート逃走という挙動も一致 |
| 🐙 | アクエーター | 原作A(Aquator)。初期版Rogueでは"rust monster"という名前で、D&Dの著作権問題によりRogue 5.3前後で改名された経緯がある(元ネタのD&D "rust monster"自体はアルマジロ寄りの虫っぽいデザインで水生生物ではない)。原作には見た目の設定が無いため、"aqua-"という名前の語感だけを頼りにタコを充てている |
| 👹 | オーク | 原作O(Orc)。撃破時に金貨を落とす習性も一致 |
| 🐉 | ドラゴン | 原作D(Dragon、炎を吐く西洋ファンタジー/D&D型)。ただしUnicodeの🐉自体は各社の実装で中華ドラゴン風(長い胴・ヒゲ・角、翼なし)に寄りがちで、原作のイメージとは食い違う。ただし絵文字の安定基準(単一コードポイント・VS16不要)を満たす西洋ドラゴン表現の選択肢が無いため代替不可 |
| 🐻 | 雪男 | 原作Y(Yeti)。イエティ専用の安定絵文字が無いため、最も近い山の獣として熊で代替(マイルストーン88) |
| 🐍 | 蛇 | 原作S(Snake) |
| 🧛 | ヴァンパイア | 原作V(Vampire) |
| 🐀 | ラット | 原作R(Rat)。直接一致 |
| 🦤 | エミュー | 原作E(Emu)。専用絵文字が無く、同じ「飛べない大型鳥」のドードーで代替 |
| 🦅 | ケストレル | 原作K(Kestrel)。専用絵文字が無く、猛禽類代表のワシで代替 |
| 😈 | ホブゴブリン | 原作H(Hobgoblin)。専用絵文字が無く、ゴブリン仮面(👺)は盗賊で使用済みのため角付き顔で差別化 |
| 🐎 | ケンタウロス | 原作C(Centaur)。専用絵文字が無く、人馬のうち馬の部分のみを充てる |
| 🦓 | クアッガ | 原作Q(Quagga)。Quagga自体が実在した絶滅シマウマの亜種のため直接一致 |
| 👤 | アーヴァイル | 原作U(Ur-vile)。原作でも設定が曖昧な影の生物のため、シルエットで妥協。最も弱いマッチ |
| 🐲 | ジャバウォック | 原作J(Jabberwock)。ドラゴン顔(🐲)は既存のドラゴン(🐉)と別コードポイントで衝突回避 |
| 🦁 | グリフィン | 原作G(Griffin)。獅子鷲のうち鷲はケストレルで使用済みのため獅子側を採用 |
| 🧌 | トロル | 原作T(Troll)。2021年(Unicode 14.0)追加の専用絵文字で直接一致(雪男・ヴァンパイアの代替が必要だった時期にはまだ存在しなかった) |
| 🦠 | イッキーシング | 原作I(Icky Thing)。「気持ち悪い盲目の粘体」に微生物のグロテスクさで代替 |
| 🌿 | ハエトリソウ | 原作F(Venus Flytrap)。食虫植物の専用絵文字が無く、「危険な植物」を漠然と示すのみ。最も弱いマッチの一つ |
| 🗿 | メデューサ | 原作M(Medusa)。専用絵文字が無く、石化効果を石像(モアイ)で暗示 |
| 🫥 | ファントム | 原作P(Phantom)。「透明・存在が薄れる」ためにデザインされた絵文字(Unicode 14.0)で意味が直撃 |
| 🥶 | レイス | 原作W(Wraith)。専用絵文字が無く、「生命力/体温を奪う」ファンタジー類型に寄せて代替 |
| 🪙 | ゼロック | 原作X(Xeroc)。金貨に擬態する原作の習性そのまま。眠っている間は💰(金貨)として描画され、目覚めて初めてこのグリフに切り替わる |

以上でA〜Zの26種を実装済み(マイルストーン101、2026-07-28)。

### アイテム(`ITEM_GLYPHS`)

| 絵文字 | 対象 | 補足 |
|---|---|---|
| 💊 | 薬全種(未鑑定含む) | 未鑑定のうちは正体を絵文字からも判別できないよう意図的に統一 |
| 🔪 | 剣 | 本来の剣ではなくキッチンナイフ(刃物という括りで意味は繋がる) |
| 🦺 | 鎧 | 本来は安全ベスト。マイルストーン75でアイテムの概念(盾→鎧)を絵文字に合わせてリネーム |
| 🍖 | 食料 | chromeの満腹度表示とも共有(「拾った物と、それで動く数値が同じ顔」) |
| 📜 | 巻物全種 | テレポート・地図・識別・武器強化・防具強化・防具保護の6種で共通。巻物は拾った時点で正体が判明するので、絵文字統一に識別上の意味はなく純粋にジャンル規約(マイルストーン72) |
| 💍 | 指輪全種(再生・満腹) | 身につけるまで正体不明、指輪という括りまでしか外見で分からない |
| 🪄 | 杖全種(攻撃・鈍足) | 旧🔮(水晶玉)から差し替え(マイルストーン73)。使うまで正体不明 |

## 却下・保留候補

同じ候補を再検討して時間を浪費しないための記録。「基準を満たさない」ものと「基準は満たすが別の理由で見送った」ものを区別している。

| 絵文字 | 検討した用途 | 却下理由 | 経緯 |
|---|---|---|---|
| 🛡️ | 盾(鎧) | VS16必須 | マイルストーン68で初出、75で最終的に概念側(鎧)をリネームする方針に転換 |
| 🔰 | 盾(鎧) | 技術基準は満たすが、日本語話者には「初心者マーク」にしか見えない。この会話で「盾っぽいバッジ」という旧コメントの主張自体が根拠なきAI由来の誤認だったと判明 | マイルストーン75 |
| 🗡️ / ⚔️ | 剣 | VS16必須(マイルストーン73で再検証済み) | |
| ❤️ | HP | VS16必須 | マイルストーン68で却下 → 💓に決着(74) |
| 🕶️ | 盲目 | VS16必須(直感的には一番わかりやすい候補だった) | マイルストーン74 |
| 👁️ | 索敵 | VS16必須 | マイルストーン74 → 🔭に決着 |
| 🫣 | 盲目 | 技術基準はクリアだが「能動的に覗いている」ニュアンスが、強制的に見えなくされる盲目の性質と逆 | マイルストーン74 → 🙈に決着 |
| 🦯 | 盲目 | 技術基準はクリアだが、実在のアクセシビリティ絵文字を一時的なコミカルデバフに転用する語調のミスマッチ | マイルストーン74 |
| 😵‍💫 | 混乱 | ZWJ結合絵文字(基準1で除外) | マイルストーン74 → 💫に決着 |
| 🪜 | 階数表示 | 安定基準違反 | マイルストーン68 |
