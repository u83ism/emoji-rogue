## ゲーム層の設計方針(2026-07-13決定)

- ゲーム層は純粋リデューサ `advanceTurn(state: GameState, action: Action): GameState`。シェル(入力読み取り・描画)だけが命令的レイヤー
- `RngState` を `GameState` に含める。乱数消費は必ず状態経由 → セーブ(GameStateのシリアライズ)・リプレイ(初期状態+アクションログ)・シード共有(デイリーチャレンジ)が構造的にほぼ無料になる
- 関数値(`passable` コールバック等)は `GameState` に入れない(シリアライズ不能・純粋性を壊す)。地形はデータとして持ち、`isPassable(state.map, x, y)` のような純粋関数で導出する
- `Action` は判別可能union(`{ type: "...", payload: {...} }`)
- 経路計算が将来ボトルネックになったら、キャッシュではなくプレイヤー起点の距離場(Dijkstraマップ)のターンごと純粋導出で対応する(`docs/tasks/modernization.md` 末尾の決定を参照)
- **ログとシステム通知の区別(2026-07-14決定)**: メッセージログ=**ゲーム世界の中の出来事**(戦闘、将来のアイテム取得・階層移動)だけを流す。`GameEvent`になりセーブ/リプレイに載る。システム通知=**アプリ/セッションの都合**(セーブしました、全角入力警告)はシェルの持ち物で、`GameState`に入れずログと1行空けて表示する。核がシェルの効果(ファイル書き込み等)を先取りしてイベント化しない。文体でも区別: ログは常体(「たおした!」)、通知はですます調(「セーブしました」)
- **i18n規律(2026-07-13決定)**: `GameState`・`Action`・将来のイベント/メッセージログに人間向け文字列を入れない。核は常にデータ(判別可能union、例: `{type:"player-hit", payload:{by:"zombie", damage:3}}`)を出し、文言化はシェル側の1箇所(将来のロケール差し替え点)に集約する。i18nライブラリの導入は実際に多言語化するときまで不要。絵文字は言語中立なので翻訳面積は元々小さい。日本語等のCJK文言はchrome行限定(マップグリッドに文字列を混ぜない既存規律の適用)

### 本家との差分(ルール・バランス)

- [ ] **視界を本家どおりにする**(2026-11-20、テストプレイ中の本人の指摘「原作の段階でこれなん？」を受けて。現行はrot.js由来のshadowcasting・半径8で、本家とは別物): ①明るい部屋は入った瞬間に部屋全体と中の敵が見える(`rooms.c`の`enter_room()`) ②暗い部屋と通路は周囲1マス(斜め含む、`LAMPDIST`=距離の2乗が3未満)しか見えない(`chase.c`の`cansee()`・`see_monst()`) ③暗い部屋は出ると床の記憶が消え、壁・扉だけ残る(`leave_room()`) ④部屋が暗くなる確率は`rnd(10) < 階-1`で、1階は0%・2階10%…11階以降は必ず暗い(`do_rooms()`)。部屋の矩形と明暗を`GameState`に持つ必要がある(セーブ形式の変更)。敵が起きる判定・BOTの探索も視界に依存しているので一緒に見直す
- [ ] **力の回復の薬と持続の指輪**: 力の回復(`P_RESTORE`)は力を最大値に戻す。持続の指輪(`R_SUSTSTR`)は毒薬・サソリ・矢のわなで力が下がるのを防ぐ。マイルストーン117で力が下がるようになったのに、戻す・防ぐ手段がまだ無い。2026-11-20のテストプレイで本人が「罠などで下がった力が減る一方」と指摘。本家の力の回復の薬は出現の重み13/91(約14%、`extern.c`の`pot_info[]`)で、治癒の薬と並んで最も出やすい薬なので、本家では気軽に戻せる。怪力の指輪(`R_ADDSTR`)は「指輪」の項目に含まれる
- [ ] **盗賊・ニンフは命中判定に当たってから盗む**: 現行は隣接すると必ず盗む
- [ ] **強化の巻物は装備中のものに効く**: 現行は持ち物から対象を選ぶ
- [ ] **透明な敵(ファントム)を本家どおりに**(2026-11-20、`chase.c`の`see_monst()`・`potions.c`・`fight.c`で確認): 本家の透明な敵(`ISINVIS`)は、透明なものが見える状態(`CANSEE`。透明視の薬`P_SEEINVIS`か透明視の指輪`R_SEEINVIS`)でなければ**隣にいても見えない**。現行は隣のマスに来ると見える(`frame.ts`)。敵感知の薬(`P_MFIND`の`turn_see()`)は透明な敵も含め全部の敵を映す——ここは現行と同じ。見えない敵はメッセージで「something」(何か)と呼ばれる(`set_mname()`。敵感知中は実名)。透明視の薬・指輪は未実装なので一緒に入れる
- [ ] **アイテムの出方を本家に**(`things.c`の`new_thing()`・`extern.c`の`*_info[]`の出現率): 本家は1階につき9回の抽選で、まず種別(薬・巻物・食料・武器・防具・指輪・杖)を、次に種類を出現率の重みで選ぶ。現行は種類ごとに独立の確率で、食料だけ本家の式を別建てで真似ている
- [ ] **指輪**: 本家の14種のうち未実装の9種(怪力・保護・持続・命中・ダメージ・索敵・透明視・テレポート・鎧の維持など)を入れる。本家は**左右の手に1つずつ、2つまで**装備できる(`rings.c`)——現行の1枠と「2個目が無駄」問題(`game-notes.md`)はこれで解消する。数値を持つ指輪は「1/3で呪い・効果値-1、それ以外は+1か+2」の抽選、テレポートの指輪は必ず呪い
- [ ] **薬・巻物・杖の網羅**: 本家の薬14種・巻物18種・杖14種のうち未実装のものを入れる(`docs/rogue-5.4-spec.md`のアイテム表)。薬の未実装は透明視・魔法感知・超回復・加速・力の回復(2026-11-21、本家に無い生命の薬・麻痺の薬を削除した後の残り)
- [ ] **杖の回数と鈍足の杖を本家どおりに**(2026-11-21、本家に無い杖を削除した作業中に`sticks.c`で確認): 本家の杖は使える回数を持ち(`fix_stick()`。3〜7回、光の杖だけ10〜19回)、回数が尽きると効かなくなる。現行は1回使うと消える。鈍足の杖は本家では敵に恒久的な鈍足(`ISSLOW`、`do_zap()`)をかけ、加速中の敵なら加速を解くだけ——現行は`SLOW_WAND_DURATION`ターンの行動不能。勝ったときの持ち物の換算(`total_winner()`)にある「残り回数×20」も、回数を入れると効くようになる
- [ ] **未鑑定の見た目を本家どおりランダムに**: 本家は薬に色、巻物に題名、指輪に宝石、杖に材質を、ゲームごとにランダムに割り当てる(`init.c`)。現行は薬が全部「未鑑定の薬」、指輪・杖は全部「指輪」「杖」(使えば以後実名、2026-11-20)、巻物は最初から実名
- [ ] **わなを本家どおりに**: 本家のわなは踏んでも消えず、見えるようになって残る。探す(`s`)で隣のわなを見つけられる。現行は1回で消え、二度と見えない。本家の矢のわな(`T_ARROW`: 1d6、外れた矢が足元に落ちる)も未実装(現行の「矢のわな」は本家の`T_DART`相当)
- [ ] **投げる方向を選べるように**: 本家は方向を選び、敵がいなくても投げられる。現行は視界内の最も近い敵への自動照準
- [ ] **敵の持ち物**: 本家の敵は出現時に`carry%`の確率でアイテムを持ち、倒すと落とす(`give_pack()`、最深到達階のときだけ)
- [ ] **27階以降で敵が強くなる処理**(`lev_add`)
