# emoji-rogue

絵文字で描画するCLIローグライク。ASCIIの制約下で表現を磨いたRogueの精神を、「等幅ではないが意味を持つ記号」である絵文字で現代的にやり直す試み(絵文字ゲームシリーズ第1弾)。

土台は[rot.js](https://github.com/ondras/rot.js)のフォークで、マップ生成・FOV・経路探索・ターン制スケジューリングを関数型スタイル+最新TypeScriptに全面書き換えたもの。その上に純粋リデューサ方式のゲーム層とInk製絵文字レンダラーを載せている。

## 現在の状態

一通り遊べる状態です: diggerが生成したダンジョンに潜り、視界(shadowcasting・既踏破は記憶表示)の中で敵と戦い、アイテムを使い、10階の魔除けを持ち帰ります。進捗は [docs/tasks/game.md](docs/tasks/game.md) を参照。

- **目的**: 地下10階にあるイェンダーの魔除け💎を手に入れ、上り階段🔼で地上まで戻ると勝利🎉。魔除けなしで地上に出るとただの帰還(その場で終了)
- **敵**: ゾンビ🧟(標準)・コウモリ🦇(1ターンに2回行動する代わりにHP1)は深さに応じて出現数が増える。盗賊👺は所持金を、ニンフ👻は持ち物を1つ盗んで盤面から消える(倒す必要はない)。アクエーター🐙は攻撃のたびに確率で防具を錆びさせる(防御力ダウン)。全ての敵は最初眠っており、隣接するか視界に入ると毎ターン確率で目を覚ます。まだ眠っている敵への攻撃は3倍ダメージの不意打ち
- **モンスターハウス**: 稀に、最初から警戒済みの敵が大量に詰まった部屋が生成される
- **戦闘とレベル**: 移動先に敵がいるとバンプ攻撃。敵を倒すと経験値が入り、レベルアップで最大HPが伸びる。HPが0で死亡
- **装備・強化**: 剣🔪(攻撃力+1)・鎧🦺(防御力+1)は使うと恒久強化。まれに呪われていて逆に下がる(使うまで分からない)。武器強化・防具強化の巻物📜は呪いなしの確実な強化。防具保護の巻物📜でアクエーターの錆びを無効化。現在の攻防値はステータスバーに常時表示
- **未鑑定ポーション**: 💊は回復・毒・怪力・混乱・浮遊・盲目・麻痺・レベルアップ・索敵・生命の10種があり、どれも見た目が同じ。「未鑑定の薬」を飲むか識別の巻物📜で鑑定するまで正体は分からない。混乱(移動がランダム化)・盲目(視界が激減)・麻痺(数ターン行動不能)は罠、浮遊(わなを踏まない)・索敵(視界外の敵が見える)・生命(最大HP+5)は当たり
- **巻物・指輪・杖**: 巻物📜はテレポート・地図(フロア全体を踏破扱いに)・識別・武器強化・防具強化・防具保護の6種で、拾った時点で正体が分かる(絵文字は種別で統一)。指輪💍は再生(HP自然回復)と満腹(空腹の進みが遅くなる)の2種で、身につけるまでどちらか分からない。杖🪄も攻撃(視界内の最も近い敵に遠隔ダメージ)と鈍足(敵を数ターン封じる)の2種で、使うまで分からない
- **満腹度**: ターン経過で減り、尽きるとHPが削れ続ける。食料🍖で回復
- **金貨**: 💰を踏むと自動回収。スコアの主成分
- **わな**: 踏むまで見えない。ダーツ(ダメージ)・落とし穴(次のフロアへ強制落下)・テレポート(フロア内のどこかへ飛ばされる)。浮遊中はどれも踏まない
- **クロンの風**: 同じフロアに長居しすぎると警告が出て、やがて強制的に次のフロアへ吹き飛ばされる
- **コンダクト**: 一度も攻撃しない「非殺生」・一度も食べない「不食」を最後まで守り切ると、終了時に称号とスコアボーナス
- **セーブ・リプレイ**: `s`キーで中断セーブ(1スロット。次回起動時に自動再開し、ファイルは消費される)。ランの操作ログは`~/.emoji-rogue/replay.json`に記録され、シードと合わせて全ターンを再現できる

## 遊び方

```
npm ci
npm run build
npm start
```

シードを指定して始めたい場合は `npm start -- --seed=12345`(ブラウザデモの`?seed=`と同じ役割)。

- 移動: 矢印キー または hjkl
- 待機: `.` またはスペース(隣接する敵はそれでも攻撃してくる)
- 持ち物: `i`で開閉。表示された文字キー(a, b, c...)で使用するアイテムを選ぶ。`i`または`Esc`でキャンセル
- セーブ: `s`
- 終了: `q`(またはCtrl+C)

**半角入力モードでプレイしてください。** IME(日本語入力)が全角モードのままだと、矢印キー以外のキー(hjkl・待機・持ち物・セーブ・終了)がIMEの変換バッファに吸われて届きません。全角入力を検知すると画面に警告が表示されます。

## 動作環境(重要)

- **Node.js >= 20**
- **Windows Terminal必須**(Windows 11の既定ターミナルであればそのままでOK)。カラー絵文字はターミナルのフォントフォールバック(Segoe UI Emoji)で描画されるため、設定フォント自体は等幅フォントなら何でもよい。**推奨フォント**: Windows Terminalの既定フォント(Cascadia Mono/Cascadia Code)でそのまま動作確認済み。フォントを変えていない・変えたくない場合はそれで問題ない
- 旧コンソールホスト(conhost)はカラー絵文字を描画できないため**非対応**
- macOS/Linuxの各種ターミナルは未検証(カラー絵文字+全角幅のフォールバックが効く環境なら動く見込み)

**表示崩れは既知の制約であり、バグとは限りません。** 絵文字の描画幅・対応範囲はターミナル・OS・フォントの世代に依存します。本プロジェクトは実行時の幅計測を意図的に行わず(絵文字では信用できないため)、1タイル=2カラム決め打ち+技術的に安定した絵文字の厳選で対処しています。これは「フォント設定はユーザーが合わせる」という旧来ローグ文化の現代的踏襲です。詳細は [docs/design.md](docs/design.md)。

## ブラウザデモ

ターミナル環境が用意できない場合向けに、`demo/`にビルド不要のブラウザ版があります。絵文字幅問題(端末最大の地雷)はCSSでセル幅を明示できるブラウザには存在しません。セーブは`localStorage`に毎ターン自動保存され(CLI版の`s`キー手動セーブと違い、タブがいつ閉じられるか分からないため)、次回開いたときに自動再開します(1スロット・消費型でCLI版と同じ)。リプレイは非対応です。

```
npm run build
npx serve .   # または python3 -m http.server などリポジトリルートで静的配信できれば何でもよい
```

ブラウザで `demo/index.html` を開いてください(`file://`ではESモジュールのimportがCORSでブロックされるため、必ず簡易サーバー経由で開くこと)。`?seed=123` のようにURLパラメータでシードを指定できます。

## 近代化rot.jsコアだけ欲しい場合

ゲーム固有のコードを含まない「近代化されただけのrot.js」は **`modernization`ブランチ**(タグ `modernization-complete` 相当)として独立に保存しています。マップ生成器8種・FOV・A*/Dijkstra・スケジューラ等を、原本と挙動互換(乱数消費順まで一致検証済み)のままESM+strict TypeScript+クラスなしで使えます。詳細はそちらのREADMEを参照。
