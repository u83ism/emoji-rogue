# タイトル

絵文字ゲームシリーズ構想（第1弾: 絵文字ローグ／第2弾候補: 絵文字4X）

# 概要

絵文字を「装飾」ではなく「Unicodeで標準化された、意味を持つピクトグラム集合」として捉え、それを主軸に据えたゲームシリーズを作る構想。90-00年代初頭は「アホなJKが使うもの」という印象だった絵文字が、国際規格化して国際コミュニケーション上・リッチCLIの文脈でも重要になっているという認識が出発点。

# 第1弾: 絵文字ローグ（CLIゲーム）

- **技術駆動／ルネッサンス的な意図**: Rogue系はASCIIという制約下での表現最適化から生まれた。絵文字は「等幅でないが意味を持つ記号」という点でASCIIの現代的後継と解釈できる。CLI×Unicode×TUIライブラリは「使えるが誰もやらない」実験領域であり、Webでやると凡庸になる
- 採用ライブラリ: **rot.js**（JS向けOSSローグライクライブラリ。マップ生成・FOV・パスファインディング・ターン制処理を提供）
- **カラー絵文字は必須**（白黒記号扱いにするとインパクトが無さすぎるため）。その代償として生じる技術的地雷への対処方針:
  - 論理セルと描画セルを完全分離する（1タイル=1意味の論理グリッドに対し、描画は1タイル=横2文字のセル幅で固定する。`TILE_W = 2` で `x * TILE_W` に描画を寄せる）
  - 絵文字幅の実行時計測（wcwidth等）は絵文字では信用できないため、設計で決め打ちする
  - 絵文字セットは「技術的に安定しているカテゴリ」（人物・モンスター・地形・アイテムの基本形）に厳選し、組み合わせ絵文字（ZWJ）・国旗・肌色修飾・最近追加された絵文字は避ける
  - Windows Terminal必須・推奨フォント明記など、環境依存であることをREADMEで明文化する（「表示崩れは既知の制約であり、バグとは限らない」という一文が必須）。これは技術的怠慢ではなく、旧来のローグが「フォント設定はユーザーに合わせさせる」文化を持っていたことの現代的踏襲

# 第2弾候補の検討

CLI縛りを外して検討した候補（優先度順ではなく列挙）:

1. **絵文字4X／文明発展シミュレーション**（最有力）
2. 絵文字カードゲーム（記号構文バトル。例: 🔥+🌲=🌋、🧠+💻=🤖）
3. 絵文字RTS（抽象化された戦場、視認性重視）
4. 絵文字経営シミュレーション
5. 絵文字言語パズル（絵文字のみで文章を作る制約ゲーム）
6. 絵文字都市生成サンドボックス
7. 絵文字生態系シミュレーション
8. 絵文字“意味進化”シミュレーション（ミーム進化ゲーム。🔥が「火」→「流行」→「最高」に意味変化する等、社会学的テーマとの相性が良い）
9. 絵文字外交・翻訳ゲーム（言語のない文明同士が絵文字のみで交渉。完全非言語UI）
10. 絵文字都市オートマトン（セル・オートマトンで都市が進化、プレイヤーはルール改変のみ可能）
11. 絵文字記号プログラミングゲーム（Human Resource Machine系だが完全視覚記号）

## 4X案の深掘り: 農業・生活圏中心のAgrarian 4X

絵文字のカテゴリ分布の偏り（顔・動物・食べ物は絵文字が豊富、建築・地形・制度は相対的に少ない。RPGは戦闘・キャラ中心になりやすくカテゴリが偏る）を踏まえ、**戦争要素を少なめにしてファーミング要素を強めにする**方向性が「絵文字のバリエーションを活かす」という観点で最適と判断した。

- 戦争特化4X ＜ バランス型4X ＜ 農業・生活圏中心4X の順でカテゴリ活用度が高い
- 使えるカテゴリ例: 🌾🥕🍅（作物）、🐄🐓🐑🐝（家畜・昆虫）、🌧️☀️🌪️❄️（気象）、🏠🏡🏘️（住宅）、🍞🥛🧀（加工）、🚜🚚🚢（物流）、🎉🎭🎶（文化）
- 絵文字の「多義性」を活かす設計（🐄=食料/交易資源/宗教象徴、🌳=木材/環境指数/観光資源）
- 「季節制」の導入（🌱春=播種、☀️夏=成長、🍂秋=収穫、❄️冬=備蓄）で絵文字の視覚的変化をUIそのものに使う
- 「動物進化ツリー」（🐑→🧶→👕、🐄→🥛→🧀）は軍事より圧倒的にバリエーションが出る
- テンポが緩くなる・競技性が弱まるリスクへの対策として、気候災害（🌪️🌋🌊）、病害虫（🦠🐛）、市場暴落（📉）を周期的に発生させる案
