# 実機テストで見る項目

Windows Terminal(CLI版)とブラウザ版(`demo/`)で、人が実際に操作して確認する項目のリスト。自動テストでは見られないもの(表示の崩れ・操作の流れ・ログの読みやすさ)だけを載せる。**難度や手応えなどゲームバランスの項目は載せない**(バランスは後からまとめて調整する)。

- 出どころは`game-history.md`の「実機確認は未実施」とチェックの付いていない実機スモークテスト項目(2026-11-16に棚卸し)
- 確認したら`[x]`にして日付を書く。問題があれば項目の下に書き足し、`game.md`のバックログに積む
- 新しく実機確認が必要な変更をしたら、ここに項目を足す

## A. マイルストーン110〜112の変更

### 表示

- [ ] 1. 持ち物オーバーレイで「メイス(命中+1・ダメージ+1)」「リングメイル(防御4)」が1行に収まる。「バンデッドメイル」「スプリントメイル」など長い名前でも崩れない

### 動作

- [ ] 7. 新規開始時にメイスとリングメイルが装備済み(✅付き)で、食料を1個持っている
