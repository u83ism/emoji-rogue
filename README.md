# emoji-rogue

絵文字で描画するCLIローグライク。ASCIIの制約下で表現を磨いたRogueの精神を、「等幅ではないが意味を持つ記号」である絵文字で現代的にやり直す試み(絵文字ゲームシリーズ第1弾)。

土台は[rot.js](https://github.com/ondras/rot.js)のフォークで、マップ生成・FOV・経路探索・ターン制スケジューリングを関数型スタイル+最新TypeScriptに全面書き換えたもの。その上に純粋リデューサ方式のゲーム層とInk製絵文字レンダラーを載せている。

## 現在の状態

一通り遊べる状態です。ルールとバランスは原作Rogue 5.4のまま(`lcn2/rogue5.4`のソースで確認)で、見た目と操作感とコードだけを現代化しています。進捗は [docs/tasks/game.md](docs/tasks/game.md)、敵・アイテム・わなの数値の全一覧は [docs/catalog.md](docs/catalog.md) を参照。

- **目的**: 26階より深くにあるイェンダーの魔除け💎を手に入れ、地上まで持ち帰ると勝利🎉。階段🔽は1つで上り下りの両方に使い、上るには魔除けが要る。ダンジョンに底は無く、27階からは敵が強くなる
- **ダンジョン**: 原作と同じ3×3の部屋割り。明るい部屋は入ると全体が見え、暗い部屋と通路は周りだけ(深い階ほど暗い部屋が多い)。暗い部屋は出ると床の記憶が消える。深い階には隠し扉・隠し通路がある
- **敵**: 原作の26種(数値は5.4の表のまま)。部屋の敵は眠っていて、「意地悪な」種類だけが近づくと目を覚ます。持ち物を持って出現するものもいる。見えていない敵はログで「何か」と呼ばれる
- **移動と戦闘**: 8方向に動け、移動先の敵を殴る。命中とダメージは原作の式(力・レベル・AC・武器の補正)
- **アイテム**: 原作の武器9種・防具8種・薬14種・巻物18種・指輪14種・杖14種。薬の色・巻物の題・指輪の石・杖の素材はランごとにランダムで、使うか識別するまで正体が分からない(効き目の見えないものは使っても分からない)。杖には使用回数があり、方向を選んで振る。武器は方向を選んで投げられる
- **満腹度・わな・金貨**: 原作と同じ数値。わなは8種で、踏むか探す(`s`)と見えるようになる。スコアは持ち帰った金貨
- **セーブ・リプレイ**: `S`で中断セーブ(1スロット。次回起動時に自動再開し、ファイルは消費される)。ランの操作ログは`~/.emoji-rogue/replay.json`に記録され、シードと合わせて全ターンを再現できる

## 遊び方

```
npm ci
npm run build
npm start
```

シードを指定して始めたい場合は `npm start -- --seed=12345`(ブラウザデモの`?seed=`と同じ役割)。

- 移動: 矢印キー または hjkl、斜めは yubn(原作Rogueと同じキー)
- 待機: `.` またはスペース(隣接する敵はそれでも攻撃してくる)
- 階段: 階段🔽の上で`>`で下りる、`<`で上る(上るには魔除けが必要。原作Rogueと同じキー)
- 持ち物: `i`で開く(最大26個、原作Rogueと同じ)。表示された文字キー(a〜z)でアイテムを選び、`u`で使う/装備する、`d`で捨てる、`t`で投げる(装備していない武器のみ)。杖は`u`のあと、投げるときは`t`のあとに方向キーで向きを選ぶ。`Esc`で閉じる(開いている間の`i`は9番目のアイテムの選択キー)
- 探す: `s`(周り8マスの隠れたわな・隠し扉・隠し通路を探す。見つけたわなは🔺で表示され、踏むと何度でも作動する。深い階ほど扉や通路が隠れていることが多い)
- セーブ: `S`
- 終了: `q`(またはCtrl+C)

**半角入力モードでプレイしてください。** IME(日本語入力)が全角モードのままだと、矢印キー以外のキー(hjkl・待機・持ち物・セーブ・終了)がIMEの変換バッファに吸われて届きません。全角入力を検知すると画面に警告が表示されます。

## 動作環境(重要)

- **Node.js >= 20**
- **Windows Terminal、またはVS Codeの内蔵ターミナル**(Windows 11の既定ターミナルであればそのままでOK)。VS Codeの内蔵ターミナルはUnicode 13.0以降の絵文字を1カラムと数えるため、起動時に環境変数`TERM_PROGRAM=vscode`を見て、その絵文字の後ろに空白を1つ足して桁をそろえる。カラー絵文字はターミナルのフォントフォールバック(Segoe UI Emoji)で描画されるため、設定フォント自体は等幅フォントなら何でもよい。**推奨フォント**: Windows Terminalの既定フォント(Cascadia Mono/Cascadia Code)でそのまま動作確認済み。フォントを変えていない・変えたくない場合はそれで問題ない
- 旧コンソールホスト(conhost)はカラー絵文字を描画できないため**非対応**
- macOS/Linuxの各種ターミナルは未検証(カラー絵文字+全角幅のフォールバックが効く環境なら動く見込み)

**表示崩れは既知の制約であり、バグとは限りません。** 絵文字の描画幅・対応範囲はターミナル・OS・フォントの世代に依存します。本プロジェクトは実行時の幅計測を意図的に行わず(絵文字では信用できないため)、1タイル=2カラム決め打ち+技術的に安定した絵文字の厳選で対処しています。これは「フォント設定はユーザーが合わせる」という旧来ローグ文化の現代的踏襲です。詳細は [docs/design.md](docs/design.md)。

## ブラウザデモ

ターミナル環境が用意できない場合向けに、`demo/`にビルド不要のブラウザ版があります。絵文字幅問題(端末最大の地雷)はCSSでセル幅を明示できるブラウザには存在しません。セーブは`localStorage`に毎ターン自動保存され(CLI版の`s`キー手動セーブと違い、タブがいつ閉じられるか分からないため)、次回開いたときに自動再開します(1スロット・消費型でCLI版と同じ)。リプレイは非対応です。

```
npm run build
npx serve .   # または python3 -m http.server などリポジトリルートで静的配信できれば何でもよい
```

ブラウザで `demo/index.html` を開いてください(`file://`ではESモジュールのimportがCORSでブロックされるため、必ず簡易サーバー経由で開くこと)。`?seed=123` のようにURLパラメータでシードを指定できます。

## 近代化rot.jsコアだけ欲しい場合

ゲーム固有のコードを含まない「近代化されただけのrot.js」は **`modernization`ブランチ**(タグ `modernization-complete` 相当)として独立に保存しています。マップ生成器8種・FOV・A*/Dijkstra・スケジューラ等を、原本と挙動互換(乱数消費順まで一致検証済み)のままESM+strict TypeScript+クラスなしで使えます。詳細はそちらのREADMEを参照。
