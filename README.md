# emoji-rogue

絵文字で描画するCLIローグライク。ASCIIの制約下で表現を磨いたRogueの精神を、「等幅ではないが意味を持つ記号」である絵文字で現代的にやり直す試み(絵文字ゲームシリーズ第1弾)。

土台は[rot.js](https://github.com/ondras/rot.js)のフォークで、マップ生成・FOV・経路探索・ターン制スケジューリングを関数型スタイル+最新TypeScriptに全面書き換えたもの。その上に純粋リデューサ方式のゲーム層とInk製絵文字レンダラーを載せている。

## 現在の状態

一通り遊べる状態です: diggerが生成したダンジョンに潜り、視界(shadowcasting・既踏破は記憶表示)の中で敵と戦い、アイテムを使い、26階の魔除けを持ち帰ります。進捗は [docs/tasks/game.md](docs/tasks/game.md) を参照。

- **目的**: 地下26階にあるイェンダーの魔除け💎を手に入れ、上り階段🔼で地上まで戻ると勝利🎉。魔除けなしで地上に出るとただの帰還(その場で終了)
- **敵**: 原作Rogueの26種。レベル・AC・攻撃ダイス・経験値は原作5.4の表そのままで、HPは個体ごとに「レベル」個の8面ダイスで決まる。部屋の半分には金貨の山があり、金貨のある部屋には80%・ない部屋には25%の確率で1体ずつ配置される(原作と同じ)。種類は階が深くなるほど強いものに入れ替わる(1階はケストレル🦅・エミュー🦤・コウモリ🦇・蛇🐍・ホブゴブリン😈、ドラゴン🐉は22階以降)。飛ぶ敵(コウモリ・ケストレル・グリフィン)はプレイヤーから離れている間1ターンに2回動き、コウモリは行動の半分がでたらめな方向への移動になる(隣にいても離れていく)。それ以外は1ターンに1回行動するが、強い敵は1ターンに2〜3回攻撃する。盗賊👺(原作のレプラコーン相当)は所持金を、ニンフ👻は持ち物を1つ盗んで盤面から消える。盗賊が盗む額は金貨の山1つ分で、運が悪いと5つ分(レベルが高いほど少額で済みやすい)。盗まれる前に倒すと逆に金貨を落とす(これまでに降りた最も深い階にいるときだけ)。アクエーター🐙の攻撃はダメージが無い代わりに、命中すると防具を錆びさせる(防御力ダウン)。オーク👹も撃破すると金貨をドロップする。ヴァンパイア🧛は逃げずに戦い続け、攻撃が命中するたびそのダメージの一部を自分のHPとして回復する(出現時のHPが上限)。これとは別に、時間が経つと徘徊する敵が見えない場所に現れて向かってくる(平均して約94ターンに1体。原作と同じ)ので、同じ階に長居するほど危険が増える。部屋にいる敵は最初眠っており、隣接するか視界に入ると毎ターン確率で目を覚ます。まだ眠っている敵への攻撃は3倍ダメージの不意打ち。ゾンビ🧟・雪男🐻・ケンタウロス🐎・クアッガ🦓・サイ🦏(原作の黒いユニコーン)・ジャバウォック🐲は特殊能力を持たない。グリフィン🦁・トロル🧌は毎ターンHPが自然回復し、サソリ🦂(原作のガラガラヘビ)の攻撃は毒で力を下げることがあり、アイスモンスター🧊の攻撃はダメージが無い代わりに数ターン凍らせ(重なり続けると凍え死ぬ)、ハエトリソウ🌿はその場から動かず隣接時のみ反撃し、隣接中はプレイヤーを拘束して逃がさない(離れようとする移動はブロックされるがターンは消費する。捕まっている間はダメージが1ずつ増えていく)、メデューサ🗿は視界内にいる限り隣接していなくても確率で視線攻撃(混乱)を放つ、ファントム🫥は隣接するまで姿が見えず、ときどきでたらめに動く、レイス🥶は命中のたびに最大HPを永続的に奪う、ゼロック🪙は眠っている間は金貨の山に擬態している——以上で原作Rogueの26種モンスターを完全再現(詳細は[docs/catalog.md](docs/catalog.md))
- **戦闘とレベル**: 移動先に敵がいるとバンプ攻撃。命中判定とダメージは原作Rogueの式: 命中率は「(攻撃側のレベル+防御側のAC+武器の補正)×5%」で、自分のレベルが上がるほど当てやすく、防具でACを下げるほど当てられにくい(眠っている敵への不意打ちは必中)。防具は当たりにくくするだけで、受けるダメージは減らさない。ダメージは素手なら1d4、武器を持てばその武器のダイスに補正を足した値。HPは12から始まり、敵を倒すと経験値が入って、レベルアップごとに最大HPが1d10伸びる。戦っていない間はHPが自然に回復する(原作と同じく、レベル1で19ターンに1、レベルが上がるほど速い)。回復薬はレベルが高いほど多く回復し、満タンを超える分は最大HP+1に変わる。HPが0で死亡
- **装備**: 武器🔪・防具🦺・指輪💍は着脱可能な装備で、それぞれ1枠。武器は原作Rogueの9種(メイス2d4・長剣3d4・短剣1d6・両手剣4d4・槍2d3と、投げて使う弓・矢・ダーツ・手裏剣)、防具は8種(革鎧の防御力2〜プレートメイルの防御力7)で、絵文字は種類によらず共通。冒険は原作と同じく、命中+1・ダメージ+1のメイスと防御力+1のリングメイルを装備し、食料1つ・命中+1の弓・矢25〜39本を持って始まる。装備していない武器は持ち物から「投げる」ことができ、視界内の最も近い敵に飛ぶ(当たれば失われ、外れれば敵の近くに落ちる)。矢は弓を装備しているときだけ本来の威力(2d3)になる。矢・ダーツ・手裏剣・短剣は束で見つかり、1枠にまとめて持てる。武器は個体ごとに命中補正とダメージ補正を持つ。これとは別に、原作と同じ**力**(16で開始、3〜31)があり、命中とダメージに上乗せされる(16でダメージ+1、17以上で命中にも効く)。ステータスの💪に「力/最大値」として出る。原作と同じく、武器の10%・防具の20%は呪われていて、装備すると外せなくなるうえ、武器は命中補正が、防具は防御力が1〜3低い。逆に武器の5%・防具の8%は最初から強化されていて同じ値が1〜3高い。どちらも装備するまで分からない。武器強化の巻物📜は所持中の武器を1つ選んで命中補正かダメージ補正のどちらかを+1、防具強化の巻物📜は選んだ防具の防御力を+1し、どちらも呪いを解く。防具保護の巻物📜は選んだ防具の錆びを無効化(革鎧は元から錆びない)、解呪の巻物📜は装備中の呪いを一括で解く。防御力はステータスバーに常時表示(ダメージのダイスは原作と同じく出さない)
- **未鑑定ポーション**: 💊は回復・毒・怪力・混乱・浮遊・盲目・麻痺・レベルアップ・索敵・生命・幻覚の11種があり、どれも見た目が同じ。「未鑑定の薬」を飲むか識別の巻物📜で鑑定するまで正体は分からない。毒(力が1〜3下がる)・混乱(移動がランダム化)・盲目(視界が激減)・麻痺(数ターン行動不能)は罠、浮遊(わなを踏まない)・索敵(視界外の敵が見える)・生命(最大HP+5)は当たり、幻覚は敵の見た目だけを一時的に惑わす(実際の種類・強さ・行動は変わらない、実害のない演出枠)
- **巻物・指輪・杖**: 巻物📜はテレポート・地図(フロア全体を踏破扱いに)・識別・武器強化・防具強化・防具保護・解呪・混乱(視界内最近接の敵をランダム徘徊させる)・束縛(視界内の敵全員を数ターン封じる)の9種で、拾った時点で正体が分かる(絵文字は種別で統一)。指輪💍は再生(毎ターンHP+1)・満腹(空腹の進みが遅くなる)・隠密(敵の目覚めが遅くなる)・千里眼(敵の位置を常時察知)・警報(装備した瞬間にフロア中の敵を起こす「はずれ」枠で、必ず呪われていて解呪するまで外せない)の5種で、身につけるまでどれか分からない(一度身につけた種類は、以後持ち物欄やログで「再生の指輪」のように実名で表示される。いずれも装備中のみ効果。警報以外の指輪は呪われない)。杖🪄も攻撃・鈍足(敵を数ターン封じる)・テレポート(敵を強制移動させる)・魔法の矢(攻撃より高威力・低頻度)・眠り(敵を強制的に眠らせる)の5種で、使うまで分からない(使った種類は以後実名で表示される)
- **満腹度**: 原作Rogueと同じ数値。1300から始まって1ターンに1減り、300を切ると空腹の警告、150を切ると攻撃のダメージが下がる。0になると確率で気を失い(4〜11ターン動けない)、そのまま850ターン経つと餓死する。食料🍖は1個で1100〜1499回復(上限2000)。食料は平均して2フロアに1個しか出ないが、3フロア続けて出なければ次のフロアに必ず出る。再生の指輪は満腹度を毎ターン2、隠密の指輪は1余分に消費する
- **金貨**: 💰を踏むと自動回収。スコアの主成分。深い階ほど1つの山の額が大きい。魔除けを持って引き返す途中の階には置かれない
- **わな**: 踏むまで見えない。矢のわな(命中判定があり、当たると1d4ダメージ)・落とし穴(次のフロアへ強制落下)・テレポート(フロア内のどこかへ飛ばされる)・捕獲(数ターン麻痺)・錆び(装備中の防具の防御力が下がる)・睡眠ガス(数ターン眠り込んで動けなくなる)。浮遊中はどれも踏まない
- **コンダクト**: 一度も攻撃しない「非殺生」・一度も食べない「不食」を最後まで守り切ると、終了時に称号とスコアボーナス
- **セーブ・リプレイ**: `s`キーで中断セーブ(1スロット。次回起動時に自動再開し、ファイルは消費される)。ランの操作ログは`~/.emoji-rogue/replay.json`に記録され、シードと合わせて全ターンを再現できる

## 遊び方

```
npm ci
npm run build
npm start
```

シードを指定して始めたい場合は `npm start -- --seed=12345`(ブラウザデモの`?seed=`と同じ役割)。

- 移動: 矢印キー または hjkl
- 待機: `.` またはスペース(隣接する敵はそれでも攻撃してくる)
- 持ち物: `i`で開く(最大26個、原作Rogueと同じ)。表示された文字キー(a〜z)でアイテムを選び、`u`で使う/装備する、`d`で捨てる、`t`で投げる(装備していない武器のみ)。`Esc`で閉じる(開いている間の`i`は9番目のアイテムの選択キー)
- セーブ: `s`
- 終了: `q`(またはCtrl+C)

**半角入力モードでプレイしてください。** IME(日本語入力)が全角モードのままだと、矢印キー以外のキー(hjkl・待機・持ち物・セーブ・終了)がIMEの変換バッファに吸われて届きません。全角入力を検知すると画面に警告が表示されます。

## 動作環境(重要)

- **Node.js >= 20**
- **Windows Terminal必須**(Windows 11の既定ターミナルであればそのままでOK)。カラー絵文字はターミナルのフォントフォールバック(Segoe UI Emoji)で描画されるため、設定フォント自体は等幅フォントなら何でもよい。**推奨フォント**: Windows Terminalの既定フォント(Cascadia Mono/Cascadia Code)でそのまま動作確認済み。フォントを変えていない・変えたくない場合はそれで問題ない
- 旧コンソールホスト(conhost)はカラー絵文字を描画できないため**非対応**
- macOS/Linuxの各種ターミナルは未検証(カラー絵文字+全角幅のフォールバックが効く環境なら動く見込み)

**表示崩れは既知の制約であり、バグとは限りません。** 絵文字の描画幅・対応範囲はターミナル・OS・フォントの世代に依存します。本プロジェクトは実行時の幅計測を意図的に行わず(絵文字では信用できないため)、1タイル=2カラム決め打ち+技術的に安定した絵文字の厳選で対処しています。これは「フォント設定はユーザーが合わせる」という旧来ローグ文化の現代的踏襲です。詳細は [docs/design.md](docs/design.md)。

## ブラウザデモ

ターミナル環境が用意できない場合向けに、`demo/`にビルド不要のブラウザ版があります。絵文字幅問題(端末最大の地雷)はCSSでセル幅を明示できるブラウザには存在しません。セーブは`localStorage`に毎ターン自動保存され(CLI版の`s`キー手動セーブと違い、タブがいつ閉じられるか分からないため)、次回開いたときに自動再開します(1スロット・消費型でCLI版と同じ)。リプレイは非対応です。

```
npm run build
npx serve .   # または python3 -m http.server などリポジトリルートで静的配信できれば何でもよい
```

ブラウザで `demo/index.html` を開いてください(`file://`ではESモジュールのimportがCORSでブロックされるため、必ず簡易サーバー経由で開くこと)。`?seed=123` のようにURLパラメータでシードを指定できます。

## 近代化rot.jsコアだけ欲しい場合

ゲーム固有のコードを含まない「近代化されただけのrot.js」は **`modernization`ブランチ**(タグ `modernization-complete` 相当)として独立に保存しています。マップ生成器8種・FOV・A*/Dijkstra・スケジューラ等を、原本と挙動互換(乱数消費順まで一致検証済み)のままESM+strict TypeScript+クラスなしで使えます。詳細はそちらのREADMEを参照。
